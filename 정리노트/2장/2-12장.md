## 2-12장 답변 기능 만들기

### 1. 답변 입력 폼 만들기

```html
<form th:action="@{|/answer/create/${question.id}|}" method="post">
    <textarea name="content" id="content" rows="15"></textarea>
    <input type="submit" value="답변등록">
</form>
```

`form` 태그는 사용자가 입력한 데이터를 서버로 전송할 때 사용한다.

---

### 2. `th:action`

```html
th:action="@{|/answer/create/${question.id}|}"
```

폼을 제출했을 때 요청할 URL을 지정한다.

현재 질문의 `id`가 3이라면 다음 URL로 요청을 보낸다.

```text
/answer/create/3
```

`question.id`를 URL에 포함하는 이유는 해당 답변이 어떤 질문에 등록되는 답변인지 구분하기 위해서이다.

---

### 3. `method="post"`

```html
method="post"
```

폼 데이터를 POST 방식으로 서버에 전송한다.

HTTP 메서드는 일반적으로 다음과 같이 사용한다.

| HTTP 메서드       | 용도     |
| -------------- | ------ |
| `GET`          | 데이터 조회 |
| `POST`         | 데이터 등록 |
| `PUT`, `PATCH` | 데이터 수정 |
| `DELETE`       | 데이터 삭제 |

답변을 새로 등록하는 기능이므로 POST 방식을 사용한다.

---

### 4. 답변 입력창

```html
<textarea name="content" id="content" rows="15"></textarea>
```

`textarea`는 여러 줄의 답변 내용을 입력할 수 있는 입력창이다.

#### `name="content"`

```html
name="content"
```

서버로 데이터를 전송할 때 사용하는 이름이다.

사용자가 다음과 같이 입력했다고 가정한다.

```text
스프링 정말 재미있네요.
```

폼이 제출되면 서버에는 다음과 같은 형태로 전달된다.

```text
content=스프링 정말 재미있네요.
```

#### `id="content"`

```html
id="content"
```

HTML 문서 안에서 해당 입력창을 식별하기 위한 값이다.

`label`, CSS, JavaScript 등에서 사용할 수 있다.

#### `rows="15"`

```html
rows="15"
```

입력창의 기본 높이를 약 15줄로 지정한다.

---

### 5. 답변 등록 버튼

```html
<input type="submit" value="답변등록">
```

`type="submit"`은 폼을 서버로 제출하는 버튼이다.

사용자가 버튼을 누르면 `form`의 `th:action`에 지정된 URL로 POST 요청이 전송된다.

---

### 6. POST 요청 처리하기

```java
@PostMapping("/create/{id}")
public String createAnswer(
        Model model,
        @PathVariable("id") Integer id,
        @RequestParam(value = "content") String content) {

    Question question = this.questionService.getQuestion(id);

    // TODO: 답변을 저장한다.

    return String.format(
            "redirect:/question/detail/%s", id);
}
```

클래스에 다음과 같은 URL 프리픽스가 선언되어 있다면

```java
@RequestMapping("/answer")
```

실제 요청 URL은 다음과 같다.

```text
POST /answer/create/{id}
```

---

### 7. `@PathVariable`

```java
@PathVariable("id") Integer id
```

URL 경로에 포함된 질문 번호를 받아온다.

예를 들어 다음 요청이 들어오면

```text
POST /answer/create/3
```

`id`에는 다음 값이 저장된다.

```java
id = 3;
```

이 값을 이용하여 답변이 등록될 질문을 조회한다.

```java
Question question = this.questionService.getQuestion(id);
```

---

### 8. `@RequestParam`

```java
@RequestParam(value = "content") String content
```

폼에서 전달된 답변 내용을 받아온다.

HTML의 다음 속성과 연결된다.

```html
<textarea name="content"></textarea>
```

즉, HTML의 `name="content"`와 `@RequestParam(value = "content")`의 이름이 서로 일치해야 한다.

사용자가 다음 내용을 입력했다면

```text
스프링 정말 재미있네요.
```

컨트롤러에서는 다음과 같이 사용할 수 있다.

```java
content = "스프링 정말 재미있네요.";
```

---

### 9. 질문 조회하기

```java
Question question = this.questionService.getQuestion(id);
```

URL로 전달받은 `id`를 이용하여 답변을 등록할 질문을 조회한다.

예를 들어 `id`가 3이라면 데이터베이스에서 3번 질문을 가져온다.

---

### 10. 답변 저장하기

```java
// TODO: 답변을 저장한다.
```

현재는 아직 답변 저장 기능이 구현되지 않은 상태이다.

이후에는 일반적으로 다음과 같이 답변 서비스를 호출하여 저장한다.

```java
answerService.create(question, content);
```

답변을 저장할 때 필요한 정보는 다음과 같다.

```text
question → 답변이 등록될 질문
content  → 사용자가 입력한 답변 내용
```

---

### 11. 상세 페이지로 리다이렉트

```java
return String.format(
        "redirect:/question/detail/%s", id);
```

답변 등록 처리가 끝난 후 해당 질문의 상세 페이지로 다시 이동한다.

`id`가 3이라면 다음 문자열이 만들어진다.

```text
redirect:/question/detail/3
```

따라서 브라우저는 다음 URL로 다시 요청을 보낸다.

```text
/question/detail/3
```

---

### 전체 실행 흐름

```text
1. 사용자가 답변 입력
2. 답변등록 버튼 클릭
3. POST /answer/create/{질문 id} 요청
4. @PathVariable로 질문 id 전달
5. @RequestParam으로 답변 content 전달
6. 질문 id를 이용해 질문 조회
7. 답변 저장
8. 해당 질문 상세 페이지로 리다이렉트
```

### 핵심 정리

* `form`은 사용자가 입력한 데이터를 서버로 전송한다.
* `th:action`은 폼을 제출할 URL을 지정한다.
* `method="post"`는 데이터를 POST 방식으로 전송한다.
* `name="content"`는 서버로 전송되는 답변 데이터의 이름이다.
* `@RequestParam("content")`는 폼에서 전달된 답변 내용을 받는다.
* `@PathVariable("id")`는 URL에서 질문 번호를 받는다.
* 답변 등록 후 해당 질문의 상세 페이지로 리다이렉트한다.
