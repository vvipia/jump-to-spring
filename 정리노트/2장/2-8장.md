## 2-8장 루트 URL 사용하기

```java
@GetMapping("/")
public String root() {
    return "redirect:/question/list";
}
```

### 1. 루트 URL 매핑

```java
@GetMapping("/")
```

- `/`(루트 URL) 요청이 들어오면 `root()` 메서드가 실행된다.
- 즉, 브라우저에서 `http://localhost:8080`으로 접속했을 때 실행되는 메서드이다.

---

### 2. 리다이렉트(Redirect)

```java
return "redirect:/question/list";
```

- `redirect:`는 **지정한 URL로 다시 요청을 보내라는 의미**이다.
- 따라서 `/`로 접속하면 `/question/list`로 자동 이동한다.

실행 흐름

```text
브라우저
      │
GET /
      │
      ▼
root() 실행
      │
return "redirect:/question/list"
      │
      ▼
브라우저가 다시
GET /question/list 요청
      │
      ▼
QuestionController의 list() 실행
      │
      ▼
question_list.html 화면 출력
```

즉, **리다이렉트는 서버가 직접 화면을 반환하는 것이 아니라, 브라우저에게 새로운 URL로 다시 요청하도록 지시하는 방식이다.**
