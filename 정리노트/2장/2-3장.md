# 2-3장 ORM과 JPA 이해하기

## 1. ORM이란?

ORM(Object-Relational Mapping)은 자바 객체와 데이터베이스 테이블을 연결해 주는 기술이다.

- 자바 객체를 이용해 데이터베이스의 데이터를 저장하고 조회할 수 있다.
- 개발자가 SQL을 직접 작성하는 일을 줄여 준다.
- ORM이 객체의 상태를 바탕으로 SQL을 생성하여 데이터베이스에 전달한다.
- 데이터베이스 테이블과 매핑되는 자바 클래스를 **엔티티(Entity)**라고 한다.
- 데이터베이스 종류가 변경되더라도 자바 코드를 비교적 일관되게 유지할 수 있다.

> 📌 ORM을 사용한다고 SQL을 전혀 사용하지 않는 것은 아니다.  
> 개발자가 SQL을 직접 작성하는 대신 ORM 프레임워크가 SQL을 생성하고 실행해 준다.

---

## 2. JPA란?

JPA(Java Persistence API)는 자바에서 ORM을 사용하기 위한 표준 명세이다.

- JPA는 인터페이스와 애너테이션 등의 사용 방법을 정의한 표준이다.
- JPA 자체가 직접 데이터베이스를 처리하는 것은 아니다.
- JPA를 실제로 동작하도록 구현한 구현체가 필요하다.
- 대표적인 JPA 구현체로 **Hibernate**가 있다.

### JPA와 Hibernate의 관계

```text
JPA
 └── 자바 ORM 사용 방법을 정의한 표준

Hibernate
 └── JPA 표준을 실제로 구현한 ORM 프레임워크
```

> 📌 JPA는 규칙이고, Hibernate는 그 규칙에 따라 실제 기능을 제공하는 구현체이다.

## 3. H2 데이터베이스 의존성 추가

`build.gradle`의 `dependencies`에 다음 의존성을 추가한다.

```gradle
runtimeOnly 'com.h2database:h2'
```

- H2는 자바로 만들어진 가벼운 관계형 데이터베이스이다.
- 별도의 데이터베이스 서버를 설치하지 않고 실행할 수 있어 학습과 테스트에 자주 사용된다.
- `runtimeOnly`는 애플리케이션 실행 시에만 필요한 라이브러리를 추가할 때 사용한다.

---

## 4. H2 데이터베이스 설정

`application.properties`에 다음 설정을 추가한다.

```properties
# DATABASE
spring.h2.console.enabled=true
spring.h2.console.path=/h2-console

spring.datasource.url=jdbc:h2:~/local
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=
```

### 각 설정의 의미

#### `spring.h2.console.enabled=true`

H2 데이터베이스를 웹 브라우저에서 관리할 수 있는 콘솔을 활성화한다.

#### `spring.h2.console.path=/h2-console`

H2 콘솔에 접속할 URL 경로를 지정한다.

```text
http://localhost:8080/h2-console
```

#### `spring.datasource.url=jdbc:h2:~/local`

애플리케이션이 접속할 H2 데이터베이스의 위치를 설정한다.

- `~`는 사용자 홈 디렉터리를 의미한다.
- `local`이라는 이름의 파일 기반 데이터베이스를 사용한다.

#### `spring.datasource.driver-class-name=org.h2.Driver`

H2 데이터베이스 연결에 사용할 JDBC 드라이버 클래스를 지정한다.

#### `spring.datasource.username=sa`

데이터베이스 접속 사용자명을 설정한다.

#### `spring.datasource.password=`

데이터베이스 접속 비밀번호를 설정한다.

현재는 비밀번호를 사용하지 않으므로 빈 값으로 둔다.

> 📌 `application.properties`의 주석은 `//`가 아니라 `#`을 사용해야 한다.

## 5. JPA 환경 설정

`build.gradle`에 Spring Data JPA 의존성을 추가한다.

```gradle
implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
```

그리고 `application.properties`에 다음 설정을 추가한다.

```properties
# JPA
spring.jpa.hibernate.ddl-auto=update
```

필요한 경우 다음 설정도 사용할 수 있다.

```properties
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.H2Dialect
```

다만 Hibernate가 데이터베이스 종류를 자동으로 판단할 수 있으므로, 최근 환경에서는 `dialect` 설정을 직접 작성하지 않아도 되는 경우가 많다.

### `spring.jpa.hibernate.ddl-auto=update`

엔티티 클래스의 변경 사항을 확인하여 데이터베이스 테이블 구조를 자동으로 갱신한다.

예를 들어 엔티티에 새로운 필드를 추가하면, 그에 맞는 컬럼이 데이터베이스 테이블에 추가될 수 있다.

> 📌 `update`는 학습이나 개발 환경에서는 편리하지만, 실제 운영 환경에서는 데이터베이스 변경을 별도로 관리하는 것이 일반적이다.

---

## 6. `implementation`이란?

`implementation`은 Gradle에서 라이브러리 의존성을 추가할 때 사용하는 설정이다.

```gradle
implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
```

이렇게 작성하면 해당 라이브러리를 다음 과정에서 사용할 수 있다.

- 자바 코드 컴파일
- 애플리케이션 실행
- 테스트 실행

또한 `implementation`으로 추가한 라이브러리는 다른 모듈에 직접 노출되지 않는다.

> 📌 `implementation`은 단순히 빌드를 빠르게 하기 위한 설정이 아니라, 해당 프로젝트 내부에서 사용할 의존성을 선언하는 방식이다.
