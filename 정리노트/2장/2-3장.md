2-3장 ORM과 JPA 이해하기
1) ORM 이란
-> SQL을 사용하지 않고 DB를 관리하는 도구.
-> 데이터베이스의 테이블과 매칭되는 자바 클래스를 엔티티라고 한다.
-> DBMS의 종류에 관계 없이 일관된 자바 코드를 사용할 수 있어 유지보수가 좋다.

2) JPA 이란
-> 스프링 부트가 이용하는 API로 JPA는 인터페이스의 모음이다.
-> JPA를 수현한 실제 클래스에는 대표적으로 하이버네이트가 있다.
-> 하이버네이트는 JPA를 구현한 실제 클래스이며 ORM의 프레임워크 이다.

3) H2 데이터베이스 설치
-> build.gradle 파일 의존성에 runtimeOnly 'com.h2database:h2' 추가

4) H2 데이터베이스 사용
-> application.properties 파일에 아래 내용 추가
# DATABASE
spring.h2.console.enabled=true // H2 콘솔에 접속할건지
spring.h2.console.path=/h2-console // 콘솔로 접속하기 위한 URL 경로
spring.datasource.url=jdbc:h2:~/local // 데이터베이스에 접속하기 위한 경로
spring.datasource.driverClassName=org.h2.Driver // 데이터베이스에 접속할 때 사용하는 드라이버 클래스명
spring.datasource.username=sa // 데이터 베이스의 사용자명
spring.datasource.password=  // 데이터베이스의 비밀번 

5) JPA 환경 설정하기
-> 의존성에 implementation 'org.springframework.boot:spring-boot-starter-data-jpa'  추가
그리고 application.properties 파일 수정
# JPA
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.H2Dialect
spring.jpa.hibernate.ddl-auto=update
6) implementation 이란?
-> build.gradle 파일에서 라이브러리 설치를 위한 일반적인 설정. 이 라이브러리와 연관된 모듈을 컴파일하지않고 변경된 내용만 컴파일해 리빌드가 빠름
