## 2-7장 질문 목록 만들기

### 1. 템플릿 사용하기

기존에는 `@ResponseBody`를 사용하여 문자열을 브라우저에 직접 반환했다.

```java
@Controller
public class QuestionController {

    @GetMapping("/question/list")
    @ResponseBody
    public String list() {
        return "question list";
    }
}
```

하지만 실제 웹 애플리케이션에서는 자바 코드에서 HTML을 직접 작성하지 않고 **템플릿(Thymeleaf)** 을 사용하여 화면을 구성한다.

Thymeleaf를 사용하기 위해 `build.gradle`에 다음 의존성을 추가한다.

```gradle
implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
implementation 'nz.net.ultraq.thymeleaf:thymeleaf-layout-dialect'
```

템플릿을 사용할 경우 `@ResponseBody`는 필요하지 않다.

### 2. 데이터를 템플릿에 전달하기

```java
@RequiredArgsConstructor
@Controller
public class QuestionController {

    private final QuestionRepository questionRepository;

    @GetMapping("/question/list")
    public String list(Model model) {
        List<Question> questionList = this.questionRepository.findAll();
        model.addAttribute("questionList", questionList);
        return "question_list";
    }
}
```

#### `private final QuestionRepository questionRepository`

- `@RequiredArgsConstructor`는 `final` 필드를 매개변수로 받는 생성자를 자동으로 생성한다.
- 스프링은 `QuestionController` 객체를 생성할 때 자신이 관리하는 `QuestionRepository` 객체를 생성자에 전달한다.
- 이러한 방식을 **생성자 주입(Constructor Injection)** 이라고 한다.

#### `List<Question> questionList = this.questionRepository.findAll();`

- `findAll()` 메서드를 이용하여 데이터베이스의 모든 질문을 조회한다.
- 조회된 `Question` 객체들을 `List<Question>`에 저장한다.

#### `model.addAttribute("questionList", questionList);`

조회한 리스트를 `Model`에 저장하여 HTML에서 사용할 수 있도록 전달한다.

```text
key              value
-----------------------------------
questionList  →  List<Question>
```

### 3. HTML에서 데이터 출력하기

```html
<tr th:each="question : ${questionList}">
    <td th:text="${question.subject}"></td>
    <td th:text="${question.createDate}"></td>
</tr>
```

#### `th:each`

`questionList`에 저장된 `Question` 객체를 하나씩 꺼내 `question` 변수에 저장한다.

자바의 향상된 for문과 같은 역할을 한다.

```java
for (Question question : questionList) {
    ...
}
```

#### `th:text`

현재 `question` 객체의 값을 출력한다.

```html
<td th:text="${question.subject}"></td>
```

→ `question.getSubject()`

```html
<td th:text="${question.createDate}"></td>
```

→ `question.getCreateDate()`

### 4. 자주 사용하는 타임리프 속성

| 속성 | 설명 |
|------|------|
| `th:if` | 조건문 |
| `th:each` | 반복문 |
| `th:text` | 텍스트 출력 |

예시

```html
<!-- 조건문 -->
<div th:if="${question != null}"></div>

<!-- 반복문 -->
<tr th:each="question : ${questionList}"></tr>

<!-- 텍스트 출력 -->
<td th:text="${question.subject}"></td>
```
