## 2-13장 웹 페이지 디자인하기

### 1. `static` 디렉터리

CSS, JavaScript, 이미지처럼 브라우저에서 직접 사용하는 정적 파일은 다음 `static` 디렉터리에 저장한다.

```text
src/main/resources/static
```

예를 들어 CSS 파일의 이름이 `style.css`라면 다음 위치에 생성한다.

```text
src/main/resources/static/style.css
```

스프링 부트는 `static` 디렉터리의 파일을 자동으로 정적 파일로 인식한다.

---

### 2. 스타일시트 작성하기

`style.css` 파일에 다음 코드를 작성한다.

```css
textarea {
    width: 100%;
}

input[type="submit"] {
    margin-top: 10px;
}
```

#### `textarea`

```css
textarea {
    width: 100%;
}
```

페이지에 존재하는 모든 `<textarea>` 태그의 너비를 부모 요소의 전체 너비로 설정한다.

```html
<textarea name="content" rows="15"></textarea>
```

위 입력창이 화면의 가로 너비에 맞게 표시된다.

#### `input[type="submit"]`

```css
input[type="submit"] {
    margin-top: 10px;
}
```

`input` 태그 중에서 `type="submit"`인 요소만 선택한다.

```html
<input type="submit" value="답변등록">
```

버튼 위쪽에 `10px`의 여백을 추가한다.

---

### 3. HTML에 CSS 연결하기

HTML의 `<head>` 태그 안에 다음 코드를 추가한다.

```html
<link rel="stylesheet"
      type="text/css"
      th:href="@{/style.css}">
```

#### `rel="stylesheet"`

연결하는 파일이 스타일시트 파일임을 나타낸다.

#### `type="text/css"`

연결한 파일의 형식이 CSS임을 나타낸다.

현대 HTML에서는 생략할 수도 있다.

#### `th:href="@{/style.css}"`

타임리프를 이용하여 `style.css` 파일의 경로를 지정한다.

`style.css`가 다음 위치에 있기 때문에

```text
src/main/resources/static/style.css
```

HTML에서는 다음 URL로 접근할 수 있다.

```text
/style.css
```

---

### 전체 연결 구조

```text
src/main/resources/static/style.css
                    │
                    ▼
<link th:href="@{/style.css}">
                    │
                    ▼
HTML 페이지에 CSS 적용
```

### 핵심 정리

* CSS 파일은 `src/main/resources/static` 디렉터리에 저장한다.
* `textarea { width: 100%; }`는 답변 입력창의 너비를 전체로 설정한다.
* `input[type="submit"]`은 제출 버튼만 선택하는 CSS 선택자이다.
* `margin-top: 10px`은 답변 등록 버튼 위에 여백을 추가한다.
* `<link>` 태그의 `th:href`를 사용해 HTML과 CSS 파일을 연결한다.
