# 2-2장 간단한 웹 프로그램 만들기

## 1. 404 Not Found

- HTTP 상태 코드 중 하나
- 브라우저가 요청한 URL에 해당하는 리소스를 찾지 못했을 때 발생한다.

> 📌 핵심
> - URL 자체가 존재하지 않거나
> - 해당 URL을 처리하는 Controller가 없는 경우 발생

예시

```
GET /jump-to-spring
```

→ `@GetMapping("/jump-to-spring")`이 없다면 **404 Not Found**

---

## 2. 컨트롤러 만들어 URL 매핑하기

### `@Controller`

- 해당 클래스를 **Controller**로 등록하는 애너테이션
- 사용자의 요청(Request)을 받아 처리하는 역할을 한다.

### `@GetMapping("/jump-to-spring")`

- GET 요청이 `/jump-to-spring`으로 들어오면 해당 메서드를 실행한다.
- URL과 메서드를 연결(매핑)해 주는 애너테이션이다.

예시

```java
@Controller
public class HelloController {

    @GetMapping("/jump-to-spring")
    @ResponseBody
    public String hello() {
        return "Hello Spring!";
    }
}
```

> 📌 핵심
> 브라우저 → URL 요청 → Controller → 메서드 실행 → 결과 반환

---

## 3. 500 Internal Server Error

- 서버 내부에서 오류가 발생했을 때 나타나는 HTTP 상태 코드이다.
- 요청한 URL은 정상적으로 찾았지만, 서버가 요청을 처리하는 과정에서 예외가 발생했다.

대표적인 원인

- 메서드에서 예외(Exception)가 발생
- `null` 접근
- 데이터베이스 오류
- 반환값 처리 오류
