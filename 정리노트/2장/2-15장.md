## 2-15장 템플릿 상속하기

### 템플릿 상속이란?

여러 HTML 파일에서 공통으로 사용하는 HTML 구조(`head`, CSS, JavaScript 등)를 하나의 템플릿으로 작성하고, 다른 템플릿에서 이를 상속하여 사용하는 기능이다.

템플릿 상속을 사용하면 중복 코드를 줄이고 유지보수가 쉬워진다.

---

### layout.html

`layout.html`은 모든 템플릿이 공통으로 사용하는 부모 템플릿이다.

공통으로 사용하는 HTML 구조와 CSS 파일을 작성한다.

```html
<th:block layout:fragment="content"></th:block>
```

`content` 영역은 자식 템플릿이 내용을 채워 넣는 위치이다.

---

### layout:decorate

```html
<html layout:decorate="~{layout}">
```

`layout.html`을 부모 템플릿으로 지정하여 상속한다.

---

### layout:fragment

```html
<div layout:fragment="content">
```

부모 템플릿의 `content` 영역에 삽입될 내용을 작성한다.

---

### 전체 구조

```
layout.html
        │
        ▼
question_list.html
question_detail.html
```

공통 HTML 구조는 `layout.html`에서 관리하고, 각 페이지는 필요한 내용만 작성하여 중복을 줄일 수 있다.
