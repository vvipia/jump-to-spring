## 2-11장 URL 프리픽스 알아두기

`QuestionController`의 모든 URL 앞에 공통으로 `/question`을 붙이고 싶다면 클래스에 `@RequestMapping`을 사용할 수 있다.

```java
import org.springframework.web.bind.annotation.RequestMapping;

@RequestMapping("/question")
@RequiredArgsConstructor
@Controller
public class QuestionController {

}
```

### `@RequestMapping("/question")`

- 클래스에 `@RequestMapping`을 선언하면 **해당 컨트롤러의 모든 URL 앞에 공통 경로(프리픽스)가 추가**된다.
- 따라서 `/question`으로 시작하는 URL 요청이 들어오면 `QuestionController`에서 처리한다.

예를 들어

```java
@RequestMapping("/question")
@Controller
public class QuestionController {

    @GetMapping("/list")
    public String list() {
        return "question_list";
    }

    @GetMapping("/detail/{id}")
    public String detail(@PathVariable Integer id) {
        return "question_detail";
    }
}
```

실제 URL은 다음과 같다.

| 메서드 | 실제 URL |
|--------|-----------|
| `@GetMapping("/list")` | `/question/list` |
| `@GetMapping("/detail/{id}")` | `/question/detail/{id}` |

즉, 메서드마다 `/question`을 반복해서 작성할 필요가 없다.

---

### 변경 전

```java
@GetMapping("/question/list")

@GetMapping("/question/detail/{id}")
```

---

### 변경 후

```java
@RequestMapping("/question")
@Controller
public class QuestionController {

    @GetMapping("/list")

    @GetMapping("/detail/{id}")
}
```

클래스에 공통 URL을 지정하여 코드의 중복을 줄이고 관리하기 편리해진다.
