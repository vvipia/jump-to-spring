## 2-10장 상세 페이지 만들기

### 1. 질문 목록에 상세 페이지 링크 추가

```html
<td>
    <a th:href="@{|/question/detail/${question.id}|}"
       th:text="${question.subject}">
    </a>
</td>
```

#### `th:href`

```html
th:href="@{|/question/detail/${question.id}|}"
```

- 클릭 시 이동할 URL을 생성한다.
- `question.id` 값을 이용하여 각 질문마다 다른 URL이 만들어진다.

예를 들어

| question.id | 생성되는 URL |
|-------------|--------------|
| 1 | `/question/detail/1` |
| 2 | `/question/detail/2` |
| 3 | `/question/detail/3` |

`@{| |}` 문법은 **문자열과 변수 값을 함께 사용할 때** 사용하는 타임리프 문법이다.

#### `th:text`

```html
th:text="${question.subject}"
```

현재 `Question` 객체의 제목을 링크의 텍스트로 출력한다.

즉,

```text
제목 : 첫 번째 질문
링크 : /question/detail/1
```

형태의 `<a>` 태그가 생성된다.

### 2. 상세 페이지 컨트롤러

```java
import org.springframework.web.bind.annotation.PathVariable;

@GetMapping("/question/detail/{id}")
public String detail(Model model, @PathVariable Integer id) {
    return "question_detail";
}
```

---

### `@GetMapping("/question/detail/{id}")`

`{id}`는 **URL 경로 변수(Path Variable)** 를 의미한다.

즉, URL의 마지막 값이 계속 변경될 수 있다는 의미이다.

예를 들어

```text
/question/detail/1
/question/detail/2
/question/detail/10
```

모두 같은 메서드가 처리한다.

---

### `@PathVariable`

```java
@PathVariable Integer id
```

URL에 포함된 `id` 값을 매개변수 `id`에 저장한다.

예를 들어

```text
GET /question/detail/3
```

요청이 들어오면

```java
id = 3
```

이 된다.

> **`@PathVariable`의 변수명은 `@GetMapping`의 `{id}`와 동일해야 자동으로 매핑된다.**

---

### 실행 흐름

```text
질문 제목 클릭
        │
        ▼
/question/detail/3 요청
        │
        ▼
@GetMapping("/question/detail/{id}")
        │
        ▼
@PathVariable Integer id
(id = 3)
        │
        ▼
detail() 메서드 실행
        │
        ▼
question_detail.html 반환
```

### 핵심 정리

- `th:href`는 링크(URL)를 생성하는 타임리프 속성이다.
- `@{| |}` 문법은 문자열과 변수를 함께 사용할 때 사용한다.
- `@GetMapping("/question/detail/{id}")`의 `{id}`는 URL 경로 변수이다.
- `@PathVariable`은 URL의 경로 변수를 메서드의 매개변수로 전달받기 위해 사용한다.
