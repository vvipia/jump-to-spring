## 2-14장 부트스트랩으로 화면 꾸미기

### Bootstrap이란?

Bootstrap은 미리 만들어진 CSS와 UI 컴포넌트를 제공하는 **CSS 프레임워크**이다.

복잡한 CSS를 직접 작성하지 않아도 `class`만 지정하여 버튼, 테이블, 카드 등의 화면을 쉽게 꾸밀 수 있다.

---

### Bootstrap 적용하기

Bootstrap CSS를 사용하기 위해 HTML의 `<head>`에 다음 코드를 추가한다.

```html
<link rel="stylesheet" type="text/css" th:href="@{/bootstrap.min.css}">
```

이후 Bootstrap에서 제공하는 클래스들을 HTML 요소에 지정하면 자동으로 스타일이 적용된다.

---

### 자주 사용한 Bootstrap 클래스

| 클래스 | 설명 |
|---------|------|
| `container` | 내용을 가운데 정렬하고 적절한 너비를 지정 |
| `table` | 테이블 스타일 적용 |
| `table-dark` | 테이블 헤더를 어두운 색으로 표시 |
| `card` | 내용을 카드 형태로 표시 |
| `badge` | 작은 라벨 형태의 컴포넌트 |
| `form-control` | 입력창 스타일 적용 |
| `btn btn-primary` | 파란색 버튼 스타일 적용 |

---

### `loop.count`

```html
<tr th:each="question, loop : ${questionList}">
    <td th:text="${loop.count}"></td>
</tr>
```

`loop.count`는 `th:each` 반복문의 현재 순번을 나타낸다.

예를 들어 질문이 3개라면 다음과 같이 출력된다.

| 번호 |
|------|
| 1 |
| 2 |
| 3 |

---

### `#temporals.format()`

```html
<td th:text="${#temporals.format(question.createDate, 'yyyy-MM-dd HH:mm')}"></td>
```

날짜 객체를 원하는 형식의 문자열로 변환하는 타임리프 함수이다.

예시

```text
2026-08-05T14:35:12
        ↓
2026-08-05 14:35
```

---

### `#lists.size()`

```html
<h5 th:text="|${#lists.size(question.answerList)}개의 답변이 있습니다.|"></h5>
```

리스트의 크기(개수)를 반환한다.

예를 들어 답변이 5개라면

```text
5개의 답변이 있습니다.
```

가 출력된다.

---

### `style="white-space: pre-line;"`

```html
<div style="white-space: pre-line;"
     th:text="${question.content}">
</div>
```

사용자가 입력한 줄바꿈(`Enter`)을 그대로 화면에 출력하도록 하는 CSS 속성이다.

---

### 핵심 정리

- Bootstrap은 CSS 프레임워크로, 미리 정의된 클래스를 사용하여 화면을 쉽게 꾸밀 수 있다.
- `<link>` 태그로 Bootstrap CSS를 연결한 후 `class` 속성에 Bootstrap 클래스를 지정하여 사용한다.
- `loop.count`는 반복문의 현재 순번을 출력한다.
- `#temporals.format()`은 날짜를 원하는 형식으로 출력한다.
- `#lists.size()`는 리스트의 개수를 반환한다.
- `white-space: pre-line`은 입력한 줄바꿈을 그대로 출력한다.
